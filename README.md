# LOCO add-on per Home Assistant

Add-on di Home Assistant usati da LOCO, l'assistente di casa di Morgan.

- **LOCO orologio** (`loco_orologio`): fa da Echo all'Echo Wall Clock con una chiavetta Bluetooth vista da HA (ora,
  calibrazione delle lancette, timer)

Aggiungi `https://github.com/morgandj01/ha-loco-addons` in Impostazioni → Componenti aggiuntivi → Store → Repository.
